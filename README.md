# 🚦 Simulation & Gestion d'un Feu de Circulation (Python)

Projet académique collaboratif simulant le fonctionnement, la régulation du trafic et l'animation graphique d'un système de feux de circulation.

## 👥 Équipe & Contributions

- **Cheikhna** — Chef de projet & structure initiale
- **Salamata Dia** — Interface graphique (`gui.py`), base de données (`database.py`) et gestion du module de logs (`logger.py`)
- **Oumaziz** — Simulation graphique et animation (`SimulationAExecuterOumaziz.py`)

## 🛠️ Composants techniques

- `gui.py` : Interface utilisateur graphique.
- `database.py` : Connexion et persistance des données.
- `logger.py` : Traçabilité et enregistrement des événements du système.
- `traffic_light.py` & `scenarios.py` : Logique de gestion et cycles de signalisation.
- `turtle_scene.py` : Animation du trafic.
